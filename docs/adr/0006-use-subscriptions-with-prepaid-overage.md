# Use subscriptions with prepaid overage

Each Tenant may subscribe to multiple Product-specific Offers through one unified billing experience. Every Offer defines its own entitlements and Meter-specific Included Allowance, while additional usage consumes a Tenant-level CNY-denominated Prepaid Usage Balance that can pay across Products; User Budgets remain policy guardrails rather than separate funds. Unsecured postpaid usage and a universal cross-Meter allowance are excluded to avoid credit risk and false equivalence between unrelated units before usage accuracy and reconciliation have been proven.
