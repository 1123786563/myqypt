# Accept usage only from approved server authorities

Canonical Usage Events may be emitted only by the trusted Model Gateway for provider usage, a Product Adapter's server-side collector for Product-domain usage, or the Billing Control Plane for commercial state; browsers and external clients cannot create billable facts. Events remain immutable and price-free so that versioned Product Offer pricing can be corrected or replayed without rewriting the historical account of what occurred.
