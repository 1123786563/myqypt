# Run License Gates for every Product Version

Every Product Version receives a machine-readable License Report covering upstream source, frontend assets, plugins, model weights, runtime and build dependencies, base images, fonts, and bundled datasets. Unknown, custom, network-copyleft, or commercially ambiguous hosting rights block production until an accountable legal reviewer explicitly approves them; a prior Product approval and an engineering-admin override cannot satisfy this Gate.
