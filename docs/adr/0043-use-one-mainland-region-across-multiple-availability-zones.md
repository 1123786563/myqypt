# Use one mainland Region across multiple Availability Zones

Stage 1 remains a single-mainland-China-Region product but runs multi-node Kubernetes and HA or managed PostgreSQL, Kafka, ClickHouse, and Valkey across multiple Availability Zones, with encrypted backups in an independent failure domain. Cross-Region active-active is deferred, preserving the agreed residency and operating scope while supporting the 99.9% availability and measured RPO/RTO targets.
