# Separate Platform APIs from Product APIs

Platform APIs expose Tenant, Membership, Catalog, Product Binding, Subscription, Usage, Billing, and lifecycle concepts, while Product APIs retain native domain semantics behind Higress, OIDC, and Product-specific SDKs. Product Adapters integrate lifecycle and identity rather than inventing a universal Knowledge or Agent API; a Capability Contract is promoted only after multiple Products prove the same stable meaning.
