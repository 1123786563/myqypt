# U08 Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付设置页：租户基本信息（T03）、Billing Customer Tax Profile 入口（U06/T63）、Tenant Export 触发与状态（T70）、只读保留期横幅与重新订阅入口（T71）、擦除状态展示（T72）——覆盖租户生命周期在 Portal 侧的可见性。

**Architecture:** 页面 = /app/settings + BFF 端点：GET /portal-api/settings（租户资料 + 生命周期状态）、POST /portal-api/settings/export-requests（T70 导出触发，幂等）、GET /portal-api/settings/export-requests/{id}（导出产物状态）。导出是异步流程：requested → preparing → ready → expired，页面轮询状态，ready 后提供下载链接（Object Store 签名 URL，短时效）。只读保留期（T71）由生命周期状态自动推导：显示「只读保留中，可导出或重新订阅」，提供 U02/U05 重新订阅入口。擦除状态（T72）只读展示，不提供任何"删除"按钮（擦除由平台 Temporal 流程驱动）。

**Tech Stack:** React 19、TypeScript、Vite、Tailwind 4、TanStack Query、Vitest Browser、Playwright、Go BFF

**Spec:** [GitHub Issue 待创建（U08，#122 起，见 portal-ui-index）](https://github.com/1123786563/myqypt/issues)、docs/architecture/architecture-baseline-risk-assessment-v1.1.md §17、ADR-0011、ADR-0050、docs/superpowers/plans/2026-08-24-t70-tenant-export.md、2026-08-24-t71-read-only-retention.md、2026-08-24-t72-tenant-erasure.md

## Global Constraints

- 导出请求幂等（同 key 只触发一次）；导出状态机来自 T70，ready 后下载链接短时效且由 BFF 签名。
- 只读保留期：页面禁止出现任何新增成本型操作入口（仅允许查看/导出/重新订阅，基线 §17）。
- 擦除阶段只读：不提供取消/恢复/删除按钮；展示「擦除进行中」及 Erasure Record 摘要（脱敏）。
- 租户资料编辑（名称等）为非敏感字段；税号等敏感字段一律跳 U06 流程，不在本页重复表单。
- 页面必须隐藏非本人可见的系统信息（如 Operator 访问记录展示仅在 Admin 视图中可扩展，本计划不含）。
- 测试用内存 Export/生命周期双端；不得包含客户内容。
