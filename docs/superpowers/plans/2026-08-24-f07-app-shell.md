# F07 双层组件体系与 AppShell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在同一 React 工程中交付可复用基础组件层和平台模式层，并实现响应式、可访问、无业务越权的 AppShell。

**Architecture:** `components/ui` 是 shadcn primitives；`components/platform` 封装导航、布局、主题和命令行为。AppShell 只消费调用方提供的授权后 `NavigationGroup[]`，不自行推导权限。

**Tech Stack:** React 19.2.5, Tailwind 4.2.2, Radix UI, shadcn, Vitest Browser 4.1.4, Playwright 1.59.1

**Spec:** [Issue #107](https://github.com/1123786563/myqypt/issues/107), extraction design §§5.1–5.2

## Global Constraints

- primitives 不依赖路由、API、租户或认证；platform components 可依赖 primitives 与显式 props。
- 折叠/主题可持久化，但不得存身份或 Token。
- 键盘、焦点恢复、移动 Sheet 和 reduced motion 必须测试。

---

## File Structure

- Create `web/src/components/ui/{button,dropdown-menu,sheet,tooltip}.tsx`.
- Create `web/src/components/platform/{app-shell,command-palette,appearance-preferences}.tsx` and tests.
- Create `web/src/features/navigation/model.ts`; create `web/src/routes/app.tsx`.

### Task 1: Establish the two-layer boundary

**Interfaces:**

```ts
export type NavigationItem = { id:string; label:string; href:string; icon?:ReactNode }
export type NavigationGroup = { id:string; label:string; items:readonly NavigationItem[] }
export type AppShellProps = PropsWithChildren<{ navigation:readonly NavigationGroup[]; userMenu:ReactNode }>
```
