# U01 App Center Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 /app 首页 App Center：列出当前 Tenant 已购/可购的 Product 及其 Observed State（T19），提供进入原生 Product UI 的 SSO 入口（T24）与购买入口（U02），并证明状态展示与入口权限正确。

**Architecture:** 页面 = web/src/routes/app/index.tsx（AppShell 内）+ BFF 聚合端点 GET /portal-api/app-center。BFF 复用 Product Binding 查询（T19 Observed State）与 Catalog（T13）能力，只返回当前 TenantScope 下可见的 binding；浏览器只带 Session Cookie，不接触 Product 内部数据。状态徽章用 U00 StatusBadge，Observed State 显示规则：active →「进入产品」按钮（SSO 跳 T24 路由）；provisioning/erasing → 只读徽章 + 轮询；suspended →「查看账单」链接（U05）；absent →「购买」跳 U02。禁止 iframe（ADR 0035），进入一律整页 OIDC 跳转。

**Tech Stack:** React 19、TypeScript、Vite、Tailwind 4、TanStack Query、Vitest Browser、Playwright、Go BFF（portal-api）

**Spec:** [GitHub Issue #123](https://github.com/1123786563/myqypt/issues)、docs/architecture/architecture-baseline-risk-assessment-v1.1.md §4/§10、ADR-0019、ADR-0035、docs/superpowers/plans/2026-08-24-t19-lifecycle-state-query.md、2026-08-24-t24-weknora-oidc-sso.md

## Global Constraints

- 只展示当前 TenantScope（F11/F12）下、调用方有权限的 binding；BFF 不得返回其他 Tenant 的 binding。
- 展示 Observed State 而非 Desired State（T19）；未知状态渲染 processing 并轮询，不渲染成功/失败。
- 进入 Product 只走 T24 SSO 整页跳转；App Center 不内嵌 Product 内容。
- 无 binding 时渲染 EmptyState（U00）并给出「浏览产品目录」动作，不渲染假数据。
- 测试用内存 Identity/Query 双端 + Playwright stub BFF 响应；不得包含客户内容。
